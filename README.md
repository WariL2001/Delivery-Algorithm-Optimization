# Delivery Algorithm Optimization

This repository contains the group project for Delivery Algorithm Optimization.

The project focuses on comparing and analyzing multiple algorithms for delivery route optimization. Different algorithms will be evaluated based on their performance under various delivery scenarios.

## Project Status

🚧 Project currently under development.

The specific algorithms, dataset, and evaluation criteria will be selected as the project develops.

## Project Objectives

- Research algorithms that can be applied to delivery route optimization.
- Implement multiple algorithms for comparison.
- Analyze algorithm performance.
- Compare best-case and worst-case scenarios.
- Determine which approaches perform better under different delivery conditions.
